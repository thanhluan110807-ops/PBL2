# Skill Triage

Skill `triage` hỗ trợ phân loại và xử lý issue, cũng như pull request từ bên ngoài nếu dự án có cấu hình hỗ trợ. Người duy trì chủ động gọi skill để xem các mục cần chú ý hoặc xử lý một issue hay pull request cụ thể.

Skill hướng dẫn thu thập ngữ cảnh, kiểm tra yêu cầu hoặc lỗi, đề xuất phân loại và trạng thái, rồi chuẩn bị hướng dẫn thực hiện cho agent hoặc người phụ trách. Skill yêu cầu cấu hình ánh xạ nhãn của issue tracker; một số trường hợp cần thêm các skill `grilling` và `domain-modeling`.

Nội dung chi tiết nằm trong `.agents/skills/triage/`.
