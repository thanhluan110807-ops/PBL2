# src/model

Chức năng chính: mô tả dữ liệu nghiệp vụ.

Các file thuộc phạm vi phần B đã triển khai:

| File | Chức năng chính |
|---|---|
| `CapBac.cpp` | Định nghĩa cấp bậc và loại nhân viên. |
| `CaTrucMongMuon.cpp` | Lưu và kiểm tra nguyện vọng ca trực. |
| `NhanVienYTe.cpp` | Lớp trừu tượng chứa thông tin và trạng thái nhân viên y tế. |
| `BacSi.cpp` | Quản lý chuyên khoa, nội trú và khả năng làm trưởng ca. |
| `DieuDuong.cpp` | Quản lý điều dưỡng và thời gian trực sàng lọc. |
| `Shift.cpp` | Lưu ca trực và kiểm tra thời gian, ca đêm, cuối tuần. |
| `ShiftAssignment.cpp` | Quản lý mã, vai trò và trạng thái một phân công. |
| `DoctorParticipation.cpp` | Ghi bác sĩ thực sự tham gia khám, thời điểm và vai trò. |

Các lớp dùng chung như `Person`, `Patient`, `Visit` là điểm phối hợp; bảng này không gán toàn bộ thư mục cho thành viên B. Xem [bản đồ phần B](../../docs/member-b/BAN-DO-FILE-PHAN-B.md).
